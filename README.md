# Texture Pipette

Texture Pipette (in-game: Terrain Texture And Object Picker) is a Farming Simulator 25 mod for identifying terrain textures and paintable foliage layers directly on the map and reusing them in the construction menu.

## Features

- Picks ground textures, foliage (grass, flowers, bushes), placeable trees and supported placeable objects directly from the map
- Matching results appear in the construction menu, with multiple results shown in mixed areas
- Considers the ground textures and foliage available on the current map
- Map foliage is made available as paintable construction-menu entries where possible
- Optional free painting mode while the pipette is active
- Can be re-activated at any time; the active brush resets automatically

## How to use

1. Open the "Pipette" tab in the construction menu.
2. Press "Activate pipette".
3. Click a ground texture, foliage, bush, tree or supported object.
4. Confirm the result in the construction menu.
5. Paint or build as usual.
