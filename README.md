# Texture Pipette

Click on a texture, plant or object in the world and get it selected in the construction menu instead of scrolling through the list looking for it. In-game it shows up as "Terrain Texture And Object Picker".

## What it does

- Picks ground textures, foliage (grass, flowers, bushes), placeable trees and supported placeable objects straight off the map
- Jumps to the matching entry in the construction menu, if a spot has mixed foliage it shows every match
- Only offers what the current map actually has, so results always make sense for where you're playing
- Map foliage becomes paintable from the construction menu wherever that's possible
- Optional free painting mode while the pipette is active
- Can be reactivated any time, the active brush resets by itself

## How to use

1. Open the "Pipette" tab in the construction menu
2. Press "Activate pipette"
3. Click a texture, foliage, bush, tree or supported object
4. Confirm the result in the construction menu
5. Paint or build as usual

## Feedback

Picked something that came out wrong? Open a GitHub issue with your mod/game version, the map, and other relevant mods. `log.txt` helps if it looks like a script error.
